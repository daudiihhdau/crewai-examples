# 01 Einkaufszettel ohne Tool

## Lernziel

Ein Agent, eine Task, keine Tools. Das Beispiel ist absichtlich banal: Ein
Einkaufshelfer plant ein einfaches Abendessen.

## Besonderheiten

- Keine Tool-Nutzung.
- Keine zweite Rolle.
- Keine technischen Begriffe im Use-Case.

## Mitnehmen

- Ein Agent ist zuerst eine klar beschriebene Rolle.
- `agents.yaml` und `tasks.yaml` reichen fuer einfache Aufgaben aus.
- Ohne Tools arbeitet der Agent nur mit der Aufgabenbeschreibung.

## Start

```powershell
crewai-examples 01
```
