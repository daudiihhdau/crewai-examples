# 02 Wochenendplan mit zwei Agents ohne Tools

## Lernziel

Zwei Agents arbeiten nacheinander, aber weiterhin ohne Tools. Einer plant ein
normales Wochenende, der andere prueft, ob der Plan realistisch ist.

## Besonderheiten

- Zwei Rollen.
- Zwei Tasks.
- Kontextweitergabe von Task 1 zu Task 2.

## Mitnehmen

- Mehrere Agents sind sinnvoll, wenn sie unterschiedliche Blickwinkel haben.
- Task-Kontext gibt ein Zwischenergebnis an die naechste Rolle weiter.
- Auch ohne Tools kann CrewAI eine kleine Review-Kette modellieren.

## Start

```powershell
crewai-examples 02
```
