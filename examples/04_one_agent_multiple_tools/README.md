# 04 Tagesplan mit mehreren Tools

## Lernziel

Ein Agent nutzt mehrere Tools und macht daraus einen einfachen Tagesplan.

## Besonderheiten

- `wetter_notiz` liefert Wetter.
- `kalender_notiz` liefert Termine.
- `budget_notiz` liefert ein kleines Budget.

## Mitnehmen

- Mehrere Tools liefern unterschiedliche Kontextarten.
- Der Agent muss diese Informationen abwaegen.
- Die Aufgabe bleibt trotzdem lebensnah und leicht erklaerbar.

## Start

```powershell
crewai-examples 04
```
